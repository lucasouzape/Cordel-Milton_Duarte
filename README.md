

# Cordel Moderno

[cite\_start]Este é um projeto de uma página web estática que exibe o poema "Cordel Moderno" de Milton Duarte[cite: 1]. A página foi estilizada para proporcionar uma experiência de leitura agradável, utilizando o efeito parallax, que cria uma sensação de profundidade ao rolar a página.

## ✒️ Sobre o Poema

[cite\_start]O poema reflete sobre o impacto da tecnologia nas comunicações modernas, contrastando a era digital com a saudade das cartas escritas à mão[cite: 1, 5].

## ✨ Funcionalidades

  * [cite\_start]**Efeito Parallax**: As seções com imagem de fundo permanecem fixas durante a rolagem, criando um efeito visual dinâmico[cite: 3].
  * [cite\_start]**Design Responsivo**: O tamanho das fontes se ajusta à largura da tela, garantindo uma boa legibilidade em diferentes dispositivos[cite: 3].
  * [cite\_start]**Fontes Customizadas**: Utiliza as fontes "Passion One" e "Sriracha" do Google Fonts para uma aparência estilizada[cite: 3].
